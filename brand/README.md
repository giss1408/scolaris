# Scolaris brand

`scolaris-logo.svg`: the mark (a graduation cap on an open book, on a teal badge). Colours: teal `#0F766E` (the app accent), amber `#F59E0B` / `#FBBF24` (the cap), white pages.
The same geometry is drawn in Flutter by `app/lib/core/logo.dart`; `app/tool/render_icons_test.dart` renders the launcher icons from it (`flutter test tool/render_icons_test.dart`, then `bash tool/apply_icons.sh`).
